# E-Commerce Sales & Customer Analytics

Interactive Power BI dashboard analyzing Brazilian e-commerce sales and customer behavior using the Olist public dataset.

## Project Overview

This project provides an interactive analysis of e-commerce performance, including sales, customers, products, payment methods, delivery performance, and customer reviews.

## Objectives

- Analyze sales performance over time
- Understand customer purchasing behavior
- Identify top-performing product categories
- Analyze payment methods
- Evaluate delivery performance
- Analyze customer review scores
- Build an interactive business intelligence dashboard

## Dataset

The project uses the Brazilian E-Commerce Public Dataset by Olist.

The dataset contains information about orders, customers, products, sellers, payments, reviews, and geolocation.

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling

## Dashboard Pages

### 1. Project Overview
Introduction to the project, dataset, objectives, and technologies used.

### 2. Sales Overview
Analysis of sales, orders, customers, payment methods, and sales trends.

### 3. Product Analysis
Analysis of product categories and product performance.

### 4. Customer & Delivery Analysis
Analysis of customer behavior, delivery performance, and reviews.

## Key Features

- Interactive slicers
- Cross-filtering between visuals
- Dynamic KPIs
- Time-based sales analysis
- Product category analysis
- Payment analysis
- Customer and delivery insights

## Data Model

The dashboard uses a relational data model connecting orders with customers, products, sellers, payments, reviews, and supporting tables.
